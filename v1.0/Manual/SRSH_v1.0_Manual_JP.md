# SRSH v1.0 マニュアル（日本語）

![SRSH_v1.0_Front](../Images/SRSH_v1.0_Front.jpg)

## 概要

**SRSH** は、8Stepのシフトレジスタと、8段のサンプル＆ホールド（S&H）を組み合わせたモジュールです。  
- GATE 出力 ×8 を備えた 8Stepシフトレジスタ（DATA / XOR 入力、WRITE / DELETE ボタン付き）  
- シフトレジスタのビットの動きに連動して電圧を受け渡す8段の S&H  
- 8 つのビットを 1 本の CV にまとめる R2R 出力  
の3つを1台にまとめ、リズムとランダムな電圧を同時に作り出せます。  
S&H の入力（SOURCE）に何も挿さなければ、内蔵のホワイトノイズをサンプルします。

---

## 仕様

- **フォーマット**：Eurorack
- **幅**：8 HP
- **奥行き**：27 mm
- **消費電流**：+12V: 90mA / -12V: 40mA

> ※ ケーブルの赤いラインが -12V に接続されていることを確認してください。
> 誤接続するとモジュールが故障する可能性があります。
> **電源投入前にケーブルの向きを必ずご確認ください。**

## 各部の機能

![SRSH_v1.0_Ex](../Images/SRSH_v1.0_Ex.jpg)

1. **Clock IN**  
    クロック入力です。立ち上がりのたびに、シフトレジスタのビットが 1 段ずつ進みます（Gate 1 → Gate 8 の向き）。
    新しいビットは、その瞬間の DATA IN・XOR IN・Write / Delete ボタンの状態で決まり、段 1 に入ります。段 8 のビットは押し出されて消えます。
    最大 1kHz 程度のクロックまで追従します。
    ファームウェアの更新時は、更新用の音声の入力にもなります（「ファームウェアのアップデート」を参照）。

2. **Reset IN**  
    リセット入力です。立ち上がりで全ビットを 0 にし（Gate はすべて消灯）、同時に S&H OUT 1〜8 をすべて、その時点の SOURCE の電圧にそろえます。

3. **DATA IN**  
    シフトレジスタのデータ入力です。クロックの立ち上がりの瞬間に HIGH なら 1、LOW なら 0 が段 1 に入ります。
    ゲートやトリガー、LFO などの入力を想定しています。

4. **XOR IN**  
    XOR 用の入力です。XOR スイッチが有効のとき、DATA IN（と Write ボタン）の値と XOR IN の値の排他的論理和（XOR）が、段 1 に入る値になります。
    XOR IN が HIGH の間はデータが反転して入るので、2 つのリズムを掛け合わせたパターンを作れます。

5. **XOR Enable/Disable Switch**  
    XOR IN を使うかどうかを切り替えます。上で有効、下で無効です。無効のときは、XOR IN に何を入れても影響しません。

6. **Manual Data Write Button**  
    手動で 1 を書き込むボタンです。押している間にクロックが来ると、DATA IN に HIGH が入ったときと同じように 1 が入ります。
    XOR が有効なら、Write の 1 にも XOR IN が掛かります。

7. **Manual Data Delete Button**  
    手動で 0 にするボタンです。押している間は、DATA IN・XOR IN・Write ボタンに関わらず、段 1 に 0 が入ります（Delete が最優先）。
    押したままクロックを 8 回入れると、8 ビットすべてが 0 になります。

8. **Gate OUT (1-8)**  
    シフトレジスタの各ビットの状態を出力します。ビットが 1 の間は HIGH（約 5V）、0 の間は LOW（0V）で、LED が同じ状態を表示します。
    1 が連続しているときは、ゲートがつながったまま（長いゲート）になります。
    ビットが立ち上がるときは、対応する S&H OUT の電圧を先に更新してから Gate を出すので、Gate を合図に S&H OUT を読むモジュールでも、新しい電圧を受け取れます。

9. **R2R OUT**  
    8 つのビットを 1 本の CV にまとめた出力です（8bit の R-2R DAC）。Gate 1 が最上位ビット、Gate 8 が最下位ビットで、0V〜約 5V の 256 段階の電圧になります。LED の明るさが電圧を表します。
    ビットが流れるにつれて段階的に変わる電圧なので、クオンタイザーと組み合わせたメロディや、変調に使えます。

10. **S&H OUT (1-8)**  
    8 段のサンプル＆ホールドの出力です。LED は電圧の正負と大きさを、色と明るさで表します。
    8 段の S&H は数珠つなぎになっていて、**S&H 8 が SOURCE の電圧を取り込み、S&H 7 は S&H 8 の電圧を、S&H 6 は S&H 7 の電圧を……と、1 つ下の段から電圧を受け取ります**。
    シフトレジスタのビットは Gate 1 → 8 へ、S&H の電圧は S&H 8 → 1 へ、逆向きに流れます。
    どのタイミングで電圧を受け取るかは、起動時に選ぶ TRIG モードで変わります（「TRIG モード」を参照）。
    受け取らない段は電圧を保持し続けます。

11. **Source IN**  
    S&H 8 が取り込む電圧の入力です。LFO や Envelope、別のシーケンサーの CV など、好きな電圧を入れられます。
    何も挿さないときは、内蔵のホワイトノイズ（約 ±10V）が入るので、ランダムな電圧のシーケンスになります。

## TRIG モード

S&H が電圧を受け取るタイミングを、2 つのモードから選べます。

| モード | S&H が電圧を受け取るとき | 向いている使い方 |
| :--- | :--- | :--- |
| **毎クロックモード**（工場出荷時） | ビットが 1 の段は、クロックのたびに受け取る | 1 が連続した範囲が、すぐ上流の新しい電圧で埋まります。1 を n 個続けて入れると、S&H 8 側の n 段に新しい電圧が並びます。ビットが 0 の段は電圧を保持します |
| **立ち上がりモード** | ビットが 0 → 1 になった瞬間だけ受け取る | Gate n と S&H OUT n を 1 つの声部（ゲート + 音程）として使う場合に向いています。1 が連続している間（長いゲート）は、電圧が変わりません |

- DATA に 1, 0, 1, 0 … のように単発の 1 だけを入れたときは、どちらのモードでも同じ動きになります。
- 毎クロックモードで DATA を常に HIGH にすると、全段が毎クロック同じ SOURCE の電圧になります。

## TRIG モードの切り替え方

1. ケースの電源を切ります。
2. **Write ボタンを押したまま**、ケースの電源を入れます。
3. Gate LED が 3 回点滅したら、ボタンから手を離します。
    - **Gate LED 8 個すべてが点滅**: 毎クロックモード
    - **Gate LED 1 だけが点滅**: 立ち上がりモード

Write を押しながら電源を入れるたびに、2 つのモードが交互に切り替わります。

- 選んだモードは本体に保存され、電源を切っても変わりません。ファームウェアを更新しても保存されたままです。
- 押したままの Write ボタンは、離すまでデータの入力として扱いません。
- 切り替えたときの点滅の間（約 0.6 秒）は、Gate OUT と R2R OUT にも点滅と同じ信号が出ます。
- **Write と Delete を両方押したまま**電源を入れると、モードの切り替えではなく、ファームウェアの更新モードになります。
- リセットボタン（基板上の SW1）を押したときも、Write を押していれば同じように切り替わります。

## ファームウェアのアップデート

ファームウェアは、次のどちらかの方法で更新できます。

| 方法 | 必要なもの | 用途 |
| :--- | :--- | :--- |
| **オーディオ** | 更新用 WAV ファイル、WAV を再生できる機器、3.5mm オーディオケーブル | 通常の更新 |
| **WCH-LinkE** | WCH-LinkE（書き込み器）、Windows PC、ジャンパワイヤ | オーディオで更新できないときの復旧 |

### オーディオでのアップデート

パソコンやオーディオインターフェースで WAV ファイルを再生し、その音を **Clock IN** に入力して更新します。専用の書き込み器は不要です。

#### 用意するもの

- 更新用の WAV ファイル
- WAV を再生できる機器。次のどちらかを使ってください。
  - オーディオインターフェースのライン出力（おすすめ）
  - パソコンのヘッドホン出力
- 3.5mm のオーディオケーブル（出力機器の端子 → Clock IN）

#### 更新の前に

- 再生する機器の音量を **最大** にしてください。
- イコライザ、音量の自動調整、空間オーディオなどの **音質補正はすべて切って** ください。
- 音が小さいと更新できません。パソコンのヘッドホン出力では音量がぎりぎりのことがあります。
  - うまくいかないときは、オーディオインターフェースのライン出力を使ってください。
  - または、ゲインのあるモジュール（ミキサー、VCA など）を通して、音を大きくしてから Clock IN に入れてください。
- Bluetooth などのワイヤレス出力は使わず、ケーブルで接続してください。
- 更新中は、ほかの音（通知音など）が鳴らないようにしてください。
- 保存されている TRIG モードは、更新しても変わりません。

#### 手順

1. ケースの電源を切ります。
2. 出力機器と、モジュールの **Clock IN** をケーブルでつなぎます。
3. **Write と Delete を両方押したまま**、ケースの電源を入れます。
4. Gate LED 1 がゆっくり点滅したら、ボタンから手を離します（書き込み待ちの状態です）。
5. 更新用の WAV ファイルを最初から最後まで再生します（約 15 秒。ファームウェアのバージョンによって変わります）。
    - Gate LED が、左から順に進捗を表示します。
    - 音を受けている間は、点灯している Gate LED の次の LED が速く点滅します。
6. Gate LED 8 個すべてが約 2 秒点灯した後、新しいファームウェアで動き出したら完了です。

更新中は、シフトレジスタとしては動作しません。Gate OUT と R2R OUT には、LED の表示と同じ信号が出ます。S&H OUT は電圧を保持したままです。

#### うまくいかないとき

| 症状 | 対処 |
| :--- | :--- |
| 電源を入れても Gate LED 1 が点滅しない | Write と Delete を両方押したまま電源を入れてください。電源を入れた後にボタンを押しても、更新モードには入りません。基板上のリセットボタン（SW1）でも更新モードには入りません。必ずケースの電源を入れ直してください。 |
| Gate LED 8 個すべてが 3 回点滅して、通常の動作に戻った | Write だけを押して電源を入れたため、TRIG モードが切り替わりました。Delete も一緒に押したまま電源を入れ直してください（TRIG モードを元に戻すには、Write だけを押してもう一度電源を入れます）。 |
| 再生しても、Gate LED の速い点滅が出ない | 音が届いていません。ケーブルの接続先（Clock IN）と、音量が最大になっているかを確かめてください。 |
| 速い点滅が出たり消えたりして、進捗が進まない | 音が小さいか、音質補正がかかっています。音量を最大にし、音質補正を切ってください。ライン出力やゲインのあるモジュールを使ってください。 |
| Gate LED 8 個すべてが速く点滅する（約 3 秒） | 更新できませんでした（音の途切れ、別製品の WAV など）。電源は入れたまま、WAV を最初から再生し直してください。 |
| 途中で再生が止まった・電源が切れた | 電源を入れ直すと、ボタンを押さなくても書き込み待ちの状態になります。WAV を最初から再生し直してください。 |

更新が途中で止まっても、モジュールが使えなくなることはありません。
もう一度最後まで再生すれば、更新が完了します。

### WCH-LinkE でのアップデート

WCH-LinkE（WCH 社の書き込み器）でモジュールのマイコンに直接書き込みます。
オーディオでの更新がどうしてもうまくいかないときに使ってください。
ここでは、Windows でオープンソースの書き込みツール **minichlink** を使う手順を説明します。

#### 用意するもの

- WCH-LinkE
- Windows PC
- ジャンパワイヤ 3 本（WCH-LinkE → モジュールの J4）
- WCH-LinkE 用のファームウェアファイル（`srsh_factory.bin`）
- 書き込みツール `minichlink.exe` と `libusb-1.0.dll`
  - [ch32fun](https://github.com/cnlohr/ch32fun) リポジトリの `minichlink` フォルダにあります。2 つを同じフォルダ（例: `C:\wch-linke-flash`）に置いてください。
  - 実行には Microsoft Visual C++ 再頒布可能パッケージ（x64）が必要です。

> **注意**: WCH-LinkE で書き込むファイルは、WAV ではなく `srsh_factory.bin` です。
> このファイルには、起動時の確認に使う情報が含まれています。ほかの `.bin` を書き込むと、モジュールは電源を入れるたびに書き込み待ち（Gate LED 1 の点滅）になります。その場合は `srsh_factory.bin` を書き込み直してください。
> `srsh_factory.bin` を書き込むと、TRIG モードは工場出荷時の毎クロックモードに戻ります。

#### 初回だけ: WCH-LinkE の準備

1. **RISC-V モードにする**
    - WCH-LinkE を USB につなぎ、青い LED が点灯したままなら ARM モードです。
    - USB を抜き、**ModeS ボタンを押したまま** USB を挿すと RISC-V モードに切り替わります（青い LED が消えます）。切り替えたモードは記憶されます。
2. **ドライバを入れる**
    - [Zadig](https://zadig.akeo.ie/) を起動し、Options → List All Devices にチェックを入れます。
    - 一覧から WCH-Link の **Interface 0** を選び、ドライバを **WinUSB** にして Install Driver（または Replace Driver）を押します。
3. **動作を確認する**
    - WCH-LinkE だけを USB につなぎ、PowerShell で次を実行します。

    ```powershell
    cd C:\wch-linke-flash
    .\minichlink.exe
    ```

    - `Found WCH Link` と表示されれば準備は完了です（モジュールをつないでいないので、その後のエラーは問題ありません）。
    - 「アプリケーション制御ポリシーによってこのファイルがブロックされました」と出る場合は、エクスプローラーで `minichlink.exe` を右クリック → プロパティ →「許可する」にチェックを入れてから、もう一度実行してください。

#### 接続

モジュール裏側の基板にある 5 ピンのヘッダと WCH-LinkE を、3 本のジャンパワイヤでつなぎます。
書き込みの間、モジュールの電源は WCH-LinkE の +5V から供給します。**安全のため、先にモジュールから Eurorack の電源ケーブルを外してください。**

| ピンヘッダ | 信号 | WCH-LinkE |
| :--- | :--- | :--- |
| 1 | GND | GND |
| 2 | RX | （つながない） |
| 3 | +5V | +5V |
| 4 | TX | （つながない） |
| 5 | SWIO | SWDIO |

#### 書き込み

電源ケーブルを外した状態で、次を実行します（モジュールは WCH-LinkE から電源を受けて動きます）。

```powershell
cd C:\wch-linke-flash
.\minichlink.exe -w srsh_factory.bin flash
```

書き込みが終わったら、WCH-LinkE を外し、電源ケーブルをモジュールにつなぎ直してから、ケースの電源を入れてください（ケーブルの向きに注意してください）。新しいファームウェアで動き出せば完了です。

#### 更新モードの書き直し（上級者向け）

オーディオでの更新モードそのもの（ブートローダ）が動かなくなった場合は、WCH-LinkE で書き直せます。
ファームウェアファイルと一緒に配布される `bootloader.bin` を使い、「接続」と同じ配線で（電源ケーブルは外したまま）、次の 3 行を順に実行します。

```powershell
.\minichlink.exe -w srsh_factory.bin flash
.\minichlink.exe -a -U -w bootloader.bin bootloader -b
.\minichlink.exe -a -w +a55a37c8 option -b
```

- 3 行目は、電源投入時に更新モードのプログラムから起動するための設定（オプションバイト）です。値を変えずに入力してください。
- 3 行目の `-a` と `-b` は省略しないでください。省略すると `Error: Flash is not unlocked` と表示されて設定できません。
- 3 行目で `Warning: Make sure you're using a raw binary file.` と表示されますが、問題ありません。
- `.\minichlink.exe -r + option 16` で読み戻し、先頭が `a5 5a 37 c8` になっていれば正しく設定されています。
- 書き込みが終わったら、WCH-LinkE を外し、電源ケーブルをモジュールにつなぎ直してから、ケースの電源を入れてください。
